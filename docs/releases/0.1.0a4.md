# ForgeUI 0.1.0a4

This release combines request and worker fixes with the analytics and portable-renderer cleanup.
It preserves the strict manifest boundary and adds no runtime dependencies.

## Changes

- Unknown-app requests return 404, dependency health checks SQLite, and the rate limiter removes
  idle client buckets. Login and generation polling use the ordinary read budget.
- Request limits use the public ASGI receive interface. Long declared lengths are compared before
  integer conversion, and oversized streamed requests return 413 before a response is committed.
- The generation worker backs off idle polling from 0.1 seconds to a 2-second cap.
- Portable rendering preserves state defaults and supports typed host rows in filters/aggregates.
  Static exports disable controls while retaining accessible content and expandable summaries.
- Portable exports include their responsive container and selected design profile. Donut charts
  have category legends, per-slice summaries, inspection controls and a mobile-friendly viewport.
- Chart geometry avoids numeric overflow; percentage comparisons explicitly use percentage
  points. A rejected component preserves unaffected siblings.
- Docker installs the package non-editable at `/opt/venv` in both build and runtime stages, so
  console-script interpreter paths stay valid without shipping a second source tree.
- The component reference and wheel examples match the 48-component catalog and current version.
  Manual publishing retries can target a pushed release tag and skip files already on PyPI.

  — 54 passed.

  — 445 passed, 6 deselected; 89.11% coverage against an 85% requirement.
- `uv run pytest -q -m browser --basetemp=/tmp/forgeui-a4-browser`
  — 5 passed. Chromium verifies light/dark desktop/mobile layouts, filtering, node selection,
  disabled static controls, accessible report content and keyboard chart inspection.
- `uv build --out-dir /tmp/forgeui-a4-dist` and
  `uv run twine check /tmp/forgeui-a4-dist/*` — passed. The local wheel is 135,399 bytes,
  below the 147,456-byte budget. Fresh base and app-extra installations passed rendering,
  readiness, static-asset, 404 and request-limit smoke checks.
- `docker build -t forgeui:0.1.0a4-review .` — passed. A temporary container started through the
  image's default command, returned readiness and CSS responses, and ran the installed package
  as UID 10001 without `/app/src`. The test container was removed afterward.
- `git diff --check` — passed.

During review, three long-header regression cases initially failed with integer-conversion errors.
They now pass. The first Docker smoke check exposed invalid launcher paths after moving the
virtual environment; using the same path in both image stages resolved the startup failure.

The existing Starlette/httpx test-client deprecation warning remains. Live Ollama and other browser
engines were not exercised. SQLite and the in-process job queue still require a single service
instance per database.
