# ForgeUI 0.1.0a3

This release adds portable HTML integration, interactive analytics and structured flowcharts,
with generic sales analytics examples and authorized host data providers.

Implemented: renderer capabilities and structured results; bounded typed filters shared across
collections/charts/KPIs; sample aggregates; formatted provider metrics and absolute comparisons;
correct signed charts and proportional donut slices; safe Mermaid flowchart import/export with
explicit bounded corrections; offline SVG, accessible connection tables and node/group state.
Nested JSON Schema references, select names and mobile grid overflow are corrected. The upstream
app-owned snapshot deletion fix is included.

No runtime dependencies were added. The wheel budget is 144 KiB; existing CSS/JS transfer budgets
are unchanged. Base and app-extra wheel installations were smoke tested in a fresh environment.

select accessible names, and mobile grid overflow. The upstream Starlette/httpx deprecation warning
remains; Docker/live Ollama and external production data sources were not tested.

## Boundaries

Mermaid support is a safe flowchart subset with deterministic ForgeUI layout, not all Mermaid.js
languages or callbacks. Dense graphs use a simple lane layout. Local statistics use at most 100 rows;
Full-dataset totals, query filtering and external connectivity belong to authorized host
providers. Polling and distributed execution remain host work.
The existing process-local generation queue is not a distributed queue.
