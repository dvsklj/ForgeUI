# ForgeUI 0.1.0a5

This release adds reusable typed layout controls while preserving the strict `forgeui/1` manifest
boundary and the existing rendering, state, and security contracts.

## Changes

- Responsive grids support numeric columns, container-aware `auto` wrapping with `sm`/`md`/`lg`
  minimum item widths, and bounded small/medium/large count presets.
- `grid-item` supports bounded column and row spans. Predefined `equal`, `main-start`, and
  `main-end` ratios cover equal columns and 2:1 main/secondary compositions.
- `gap_x`, `gap_y`, `padding`, density, alignment, and equal-height options map only to trusted
  renderer tokens.
- Cards support ordered header/body/footer slots. `content-group` keeps descriptions and captions
  attached to a single child with semantic ARIA relationships.
- `disclosure` is passive native `<details>/<summary>` markup with keyboard interaction and no
  action runtime dependency.
- Layout validation reports repairable parent, slot, span, and empty-layout diagnostics. Empty
  warnings do not block valid data-driven rendering.
- The 54-entry catalog, generated schema, prompt, docs, static export, embedded fragments, and
  standalone shell share the new layout contract. Advanced styles ship in `forgeui-layout.css` so
  the core CSS remains within its 32 KiB/6 KiB budgets.
