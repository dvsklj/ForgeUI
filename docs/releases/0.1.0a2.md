# ForgeUI 0.1.0a2

ForgeUI's first published alpha is a small, typed Python package for rendering model-generated
dashboards and application surfaces without allowing a model to emit executable frontend code.

## Highlights

- 46 allowlisted components and four complete, server-owned design profiles.
- Stateful and stateless dashboard, standalone, desktop, mobile, embedded-card, and chat-artifact
  surfaces.
- FastAPI/Jinja2/HTMX integration with light, dark, and system themes and self-hosted browser assets.
- A compact system-default light/dark theme toggle and labelled operational chart axes and scales.
- Pointer and keyboard chart inspection, plus explicit safe drill-downs bound only to registered
  actions and host-owned destination IDs.
- Strict `forgeui/1` manifests, bounded expressions, immutable SQLite revisions, safe registered
  data sources and capabilities, and a bounded Google A2UI v0.9.1 importer.
- Qwen/Ollama generation with strict parsing, semantic validation, dry rendering, duplicate
  detection, and at most two repair attempts.
- A universal wheel under the enforced 128 KiB limit, with layered extras for embedded, web, HTTP,
  Ollama, serving, and complete reference-app installations.

## Install

Alpha versions require an explicit pre-release version:

```bash
python -m pip install 'forgeui[app]==0.1.0a2'
```

For an existing FastAPI application, use `forgeui` for direct rendering or `forgeui[web]` for the
mountable router and persistence layer. Add `http` or `ollama` only when ForgeUI owns those
connections.

## Verification

The release passes formatting, linting, strict typing, static security analysis, the complete
offline suite on Python 3.11 through 3.13, package metadata validation, clean-wheel imports, the
128 KiB wheel budget, and manual light/dark/responsive interaction checks across all supported
surface and persistence modes.

The live Ollama gauntlet requires an operator-provided model endpoint; provider-unavailable behavior
was verified on the release host and ordinary generation behavior is covered by scripted providers.
