# Sankey implementation review

The `sankey` catalog entry accepts annotated nodes and weighted links and renders through the
trusted HTML adapter. Pydantic props, generated JSON Schema, prompt documentation, renderer
dispatch, shipped assets and analytics documentation share the same contract. The sales example
uses registered provider fields, with an explicit scope independent of its regional row filter.

Implemented controls include bounded acyclic topology, unique identifiers and endpoint pairs,
declared endpoints, non-negative finite numeric quantities, runtime expression-result checks,
escaped SVG/text, component-local data errors, and registered navigation drilldowns. Geometry
uses a common quantity scale and reports imbalances without manufacturing balancing flows.

## Final presentation

Ribbons blend between six desaturated theme colors using renderer-owned, instance-unique SVG
paint IDs. Gradient stops and ribbon opacity give approximately 10–21% effective opacity at rest.
Labels remain above the 18 px rounded node bars. The arrow cursor and mouse-selection prevention
keep inspection unobtrusive; keyboard focus and tooltip inspection remain available.

Flow data uses a compact muted disclosure, connection/node counts and a small chevron. The final
pass removes the filled hover treatment and table-header backgrounds. Captions have 16 px padding
aligned with the cells, with separate metadata. Numeric columns align right, row labels use normal
case, and single light rules separate rows. Keyboard focus remains visible.

## Failures encountered and disposition

- Initial provider-value fixtures used a nonexistent data path (8 failures); they now use the
  existing `data.summary.total` contract path.
- Existing donut browser tests selected the first tooltip after insertion of the Sankey
  (2 failures); selectors now target their chart.
- An invalid drilldown fixture used `set_state`; it now uses registered `navigate`, preserving
  the existing action policy.
- A contrast check treated a transparent background as black; it now resolves the opaque ancestor.
- Click checks left focus tests in pointer modality (2 failures); tests now press Tab before
  keyboard inspection.
- The expanded stylesheet exceeded its former 1 KiB gzip budget. Explicit scoped budgets were
  updated as noted above; the footprint check passes.
- A combined browser/non-browser command, `uv run pytest -q -m 'not docker and not ollama'
  --cov=forgeui --cov-report=term-missing:skip-covered
  --basetemp=/tmp/forgeui-sankey-verification`, returned 15 failures/554 passes. Sync Playwright
  and pytest-asyncio conflicted: `Runner.run() cannot be called from a running event loop`.
  Both suites pass with the existing CI process split. Combined execution remains a test-runner
  limitation; unrelated runtime code was not changed to address it.
- Passing runs emit the existing Starlette/httpx TestClient deprecation warning. Live Ollama and
  Docker checks were not run.

## Scope and limitations

Sankey supports at most 40 nodes and 80 links, one common unit, and an acyclic left-to-right layout.
It does not optimize crossings or apply local row filters. Zero and very small flows retain table
annotations; subpixel ribbons can be difficult to see. Hosts aggregate upstream and publish new
immutable revisions when topology changes. Portable hosts load `forgeui-charts.css` from the
adapter's asset list.

The user reviewed the local styling and authorized a source push after the final subtle Flow data
pass. Pre-existing compact catalog, prompt and architecture edits remain local and are excluded.
