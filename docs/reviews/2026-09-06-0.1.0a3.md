# 0.1.0a3 review and cleanup — 2026-09-06

This records the initial review of Python release commit `253198e` against its parent, before
fetching the newer remote a4 commits. The checkout was initially clean. These fixes were
subsequently combined with 0.1.0a4; see its [final release checks](../releases/0.1.0a4.md).
The adjacent legacy checkout was inspected only to establish scope and was not modified.

## Findings fixed

| Problem | Result after cleanup |
| --- | --- |
| Passing host data to the portable adapter discarded manifest state defaults, so default filters stopped applying. | Host state overrides are merged over manifest defaults without mutating the caller's context. |
| Filters dropped Pydantic row objects before the renderer's normal row conversion. | Typed rows are normalized before filtering and sample aggregation. |
| The default export wrapped the entire report in HTML `inert`, hiding its content from assistive technology. | Native action/state/navigation controls are disabled and their action hooks omitted. Headings, tables, diagram content and expandable summaries remain accessible. |
| Portable fragments lacked the hosted app's layout container, squeezing mobile headings and omitting profile styling. | Each portable result includes a responsive container and its validated design profile. The host retains theme ownership. |
| A rejected donut value replaced the entire dashboard; oversized integers could escape as exceptions. | Data failures produce an error at the affected component and a structured render issue while preserving siblings. |
| Finite signed values could overflow during chart geometry calculations; percentage deltas were labelled as percentages rather than percentage points. | Geometry uses normalized arithmetic, donut shares avoid overflowing totals, percentage deltas name percentage points, and percent-format overflow displays unavailable. |
| Donut slices lacked inspection hooks and retained an unrelated single-series legend/summary. | Legends and summaries identify each category/value, slice focus exposes its value, and a dedicated viewport keeps the donut legible on mobile. |
| The component reference still listed 46 components and old filtering rules; local-wheel examples referenced a2 or renamed the wheel to an invalid filename. | The reference lists all 48 components and shared filters; current examples preserve the full a3 wheel filename. |

Validation rules and registry authority remain intact. Invalid manifests still produce no adapter
output; invalid runtime data is handled separately as a component-level rendering failure.
